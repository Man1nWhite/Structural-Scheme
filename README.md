# Structural Scheme

Одностраничный генератор структурных схем для АСУ ТП. Приложение позволяет настраивать операторные станции, серверные стойки, сетевые шкафы и шкафы автоматики, а затем экспортировать результат в SVG, PNG, JPG или Draw.io.

## Запуск

Сборка, установка и интернет не требуются:

1. Откройте `index.html` в современном браузере (папки `src/` и `vendor/` должны лежать рядом).
2. Настройте проект на вкладках **Проект**, **Операторная**, **Серверная** и **Шкафы автоматики**.
3. Используйте кнопки экспорта над предпросмотром схемы.

На вкладке **Шкафы автоматики** можно при необходимости включить **RS-485 между** и выбрать второй шкаф. Связь появится на схеме и во всех форматах экспорта.

## Сохранение проекта

- Все изменения автоматически сохраняются в браузере и восстанавливаются при следующем открытии страницы.
- На вкладке **Проект** кнопка **Сохранить проект** скачивает файл `.json`, а **Открыть проект** загружает его обратно — так проект можно перенести на другой компьютер или передать коллеге.
- **Начать заново** заменяет текущий проект демонстрационным примером (после подтверждения).

## Разработка

Требуется Node.js 20 или новее.

```bash
npm ci        # зависимости для тестов
npm test      # все тесты
npm start     # локальный сервер: http://localhost:8000/
```

Устройство проекта и правила внесения изменений описаны в [AGENTS.md](AGENTS.md).
