# Structural Scheme

Одностраничный генератор структурных схем для АСУ ТП. Приложение позволяет настраивать операторные станции, серверные стойки, сетевые шкафы и шкафы автоматики, а затем экспортировать результат в SVG, PNG, JPG или Draw.io.

## Запуск

Сборка и установка зависимостей не требуются:

1. Откройте `Structural Scheme 2026.09.04.html` в современном браузере.
2. Настройте проект на вкладках **Проект**, **Операторная**, **Серверная** и **Шкафы автоматики**.
3. Используйте кнопки экспорта над предпросмотром схемы.

Для загрузки React, Babel и Tailwind CSS при первом открытии нужен доступ к интернету, поскольку библиотеки подключаются через CDN.

При необходимости файл можно открыть через локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

После этого перейдите на <http://localhost:8000/Structural%20Scheme%202026.09.04.html>.

## Исправленная ошибка

При включённой настройке **«Показывать количества сигналов»** нулевое количество не выводилось. Например, сигнал с количеством `0` отображался как `AO`, а не `AO (0)`. Причиной была проверка значения на истинность: число `0` в JavaScript является ложным значением.

Формирование подписи вынесено в общую функцию `signalLabel`. Теперь наличие количества проверяется через `signal.n != null`, поэтому `0` считается корректным заданным значением. Одна и та же функция используется для предпросмотра SVG и экспорта Draw.io, что исключает расхождение между форматами.

## Тесты

Требуется Node.js 18 или новее. Внешние пакеты для теста не нужны.

```bash
node --test tests/signal-label.test.js
```

Тест проверяет отображение нулевого и положительного количества, скрытие количества при выключенной настройке и использование исправленной функции в обоих путях вывода.
